COMFORT Série 300 — النشر والتحديث ونظام Extensions

أولاً: نشر التطبيق
1) أنشئ مستودعاً عاماً في GitHub وارفع جميع محتويات مجلد site إلى جذر المستودع.
2) في GitHub افتح Settings ثم Pages.
3) اختر Deploy from a branch، ثم main و / (root)، ثم Save.
4) افتح رابط github.io الناتج. التطبيق يعمل دون إنترنت بعد أول زيارة ناجحة وتحميل الملفات.
5) عند تحديث ملفات التطبيق، ارفع النسخة الجديدة. تم رفع رقم ذاكرة Service Worker في sw.js لهذه النسخة.

ثانياً: Extensions
- من Menu > Extensions يمكنك استيراد إضافة ZIP، فتح الإضافات المثبتة أو تعطيلها أو حذفها.
- الإضافات تحفظ في IndexedDB على الجهاز وتعمل دون إنترنت بعد تثبيتها.
- المتجر يقرأ site/extensions/registry.json ويمكن تغيير الرابط من داخل مدير الإضافات.
- عند الاتصال بالإنترنت وفتح مدير الإضافات يتم فحص المتجر. يمكن التثبيت أو التحديث يدوياً.
- التحديث التلقائي للإضافات المثبتة يعمل عندما يختلف الإصدار ويحتوي عنصر المتجر على قيمة sha256 صحيحة. دون sha256 يبقى التحديث يدوياً.
- يوجد نموذج ZIP تجريبي في extensions/hello-extension.zip.
- طريقة بناء ZIP وصيغة registry.json موضحة في extensions/README_AR.txt.

بنية ZIP المطلوبة: manifest.json وملف entry (افتراضياً index.html) في جذر ZIP مباشرة.
مثال manifest:
{"id":"com.example.addon","name":"اسم الإضافة","version":"1.0.0","description":"وصف","entry":"index.html"}

الأمان: الإضافة تعمل داخل iframe معزول، ولا يُسمح لها بالوصول إلى localStorage أو IndexedDB الخاص بالتطبيق أو الاتصال بالشبكة من داخل مساحة الإضافة. استورد ملفات من مصادر موثوقة فقط.

ثالثاً: تطبيق Android
- افتح مجلد android في Android Studio.
- في android/app/src/main/java/com/comfort/serie300/MainActivity.java استبدل APP_URL برابط GitHub Pages الحقيقي، مع / في النهاية.
- File > Sync Project with Gradle Files ثم Build > Build APK(s).
- دعم اختيار ملفات ZIP مضاف إلى WebView.

مهم:
- يجب تشغيل الموقع عبر HTTPS لكي يعمل Service Worker وميزة Offline.
- ملفات الإضافات يتم تحديثها مستقلاً عن APK.
- تحديث محتوى GitHub Pages لا يحدّث APK نفسه؛ تحديث APK يحتاج إعادة بناء وتوزيعه وتأكيد تثبيته من Android.
- بيانات التطبيق والإضافات محلية على كل جهاز ولا تتم مزامنتها تلقائياً بين الأجهزة.


رابعاً: ما تم إصلاحه وتحسينه في هذه النسخة (لوحة التحكم)
- شريط تبويبات اللوحة كان عالقاً أسفل الشاشة ويغطي المحتوى (بسبب قاعدة nav العامة) — أصبح شريطاً لاصقاً أعلى اللوحة.
- إزالة كلمة المرور الافتراضية من الكود (تُحفظ الآن كبصمة SHA-256 فقط)، مع تنبيه ظاهر في اللوحة ما دامت كلمة المرور الافتراضية مستخدمة.
- تسجيل الدخول يعمل أيضاً خارج HTTPS (بديل SHA-256 مدمج)، وقفل مؤقت بعد 3 محاولات خاطئة يشمل الدخول وتغيير كلمة المرور والمولّد.
- مولّد السلسلة المشفّر أصبح تبويباً مستقلاً داخل اللوحة بكلمة مروره الخاصة (كان غير قابل للوصول). لم يعد إدخال كلمة مرور المولّد يتجاوز كلمة مرور المدير.
- إصلاح: حفظ الإعدادات كان يفرض الفرنسية والمظهر الفاتح عند كل تشغيل ويلغي اختيار المستخدم — صار الافتراضي "حسب اختيار المستخدم".
- إصلاح: لون الترويسة كان يتغير عند كل تشغيل حتى دون تخصيص؛ والاسم المخصص لم يكن يثبت بعد تبديل اللغة أو السلسلة.
- واجهة اللوحة بالفرنسية والإنجليزية والعربية (RTL) فعلاً، مع وضع داكن، وإشعارات بدل alert، وإظهار/إخفاء كلمة المرور.
- الشعار: تصغير تلقائي للصور، والتحقق من الروابط، ومعالجة امتلاء التخزين. النسخ الاحتياطي: تحقق من صحة الملف المستورد.
- قائمة الإضافات المثبتة داخل اللوحة، وزر PanelCut يفتح PanelCut تحديداً.
- مدير الإضافات: ملف extensions.js أصبح مصدراً واحداً (كان مكرراً داخل index.html)، تخزين الملفات بصيغة أخف، حدّ لإجمالي حجم ZIP بعد فك الضغط، حذف حالة الإضافة عند حذفها، زر الإغلاق Esc، تعطيل زر التثبيت أثناء التنزيل.
- Service Worker: مهلة 4 ثوانٍ للشبكة ثم الاعتماد على الذاكرة (لا تعليق مع شبكة ضعيفة)، وعدم تخزين الاستجابات الجزئية. رقم الذاكرة الآن v2026-11-04-4.

إصلاح 2026-11-05 (المتجر + اللغة + الثيم):
متجر Extensions:
- زر استيراد ZIP: حقل اختيار الملف نفسه صار فوق الزر تماماً (يعمل في WebView أندرويد وSafari)، وتم توسيع أنواع الملفات المقبولة، وإزالة شرط الامتداد .zip الذي كان يرفض ملفات بلا اسم/نوع واضح (التحقق يتم من بنية ZIP نفسها).
- أزرار إغلاق/رجوع: إغلاق المتجر وإغلاق الإضافة المشغّلة وزر Esc وزر الرجوع في أندرويد/المتصفح تغلق الطبقة الأخيرة فقط وتعيد المستخدم للتطبيق. تم إصلاح خلل كان يفسد سجل المتصفح (تفريغ iframe عبر srcdoc) وإلغاء مستمعي الإغلاق المكررين.
- فتح المتجر من القائمة: الزر المخفي كان يبقى ظاهراً بسبب CSS (تمت إضافة [hidden]{display:none!important})، وإذا عُطّل المتجر من Administrator تظهر الآن رسالة واضحة بدل عدم حدوث شيء.
لوحة Administrator:
- اللغة (العربية/الفرنسية/الإنجليزية): تُطبَّق وتُحفظ فور الاختيار على كل عناصر اللوحة (التبويبات، العناوين، الأزرار، الرسائل، كتلة Extensions Store) مع الاتجاه RTL، دون ضياع ما كُتب في الحقول غير المحفوظة.
- الثيم (فاتح/داكن): يُطبَّق ويُحفظ فوراً. وأي تغيير من زر الثيم في الترويسة أو من شاشة اختيار اللغة يُحفظ أيضاً ولا يُلغيه إعداد Administrator القديم بعد إعادة التشغيل.
- تم رفع رقم ذاكرة PWA إلى v2026-11-05-12. بعد الرفع افتح التطبيق مرتين مع الإنترنت ليتفعّل الإصدار الجديد.
